# ───────────────────────────────────────────────────────────────
# 🔒 torch / torchvision 故意【不】写在本文件里！
#   - PyPI / 阿里云镜像上的 Windows torch 是 CPU 构建；
#   - 若写在此处，手动跑 `pip install -r requirements.txt` 会被误判“已满足”或拉到 CPU 版，GPU 直接不可用；
#   - 因此统一由 bootstrap.ps1 第 2 步从 download.pytorch.org 单独装 CUDA 版：
#       pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
#   - 本机实测锁定的 CUDA 版本（记录备查，不要写进 requirements 以免误拉 CPU 版）：
#       torch==2.7.1+cu126
#       torchvision==0.22.1+cu126
#     （cu126 需驱动 ≥ 525；更老驱动改 cu121/cu118，见 bootstrap 的 TORCH_CUDA 变量）
# ───────────────────────────────────────────────────────────────
